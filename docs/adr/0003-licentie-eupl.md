# 3. Licentie EUPL-1.2

**Besluit:** de code valt onder de European Union Public Licence 1.2.

**Waarom:** copyleft (verbeteringen blijven open, ook bij aangepaste webversies), Nederlandstalige officiële tekst, gangbaar en goed bruikbaar voor Nederlandse overheden, en verenigbaar met onder meer GPL en AGPL.

**Overwogen:** AGPL-3.0 (vergelijkbaar, minder gangbaar bij overheden), GPL-3.0 (dekt webgebruik minder goed af), Apache-2.0 (geen copyleft).
