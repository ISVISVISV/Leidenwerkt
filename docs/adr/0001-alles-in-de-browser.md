# 1. Alles in de browser

**Besluit:** de app is een statische website; de rekenengine draait in de browser. Geen backend.

**Waarom:** de eigenaar kan geen server beheren; gratis statische hosting volstaat. Bijkomend voordeel: financiële invoer verlaat het apparaat niet.

**Gevolg:** de engine is in TypeScript (geen Python). Regeldata wordt bij de build meegebundeld; een regelwijziging vraagt een nieuwe build.
