# 4. Netto loon via jaarberekening

**Besluit:** het netto loon wordt benaderd met de jaarberekening van de inkomstenbelasting (schijven minus algemene heffingskorting en arbeidskorting), niet met de loonheffingstabellen.

**Waarom:** de tabellen zijn groot en worden niet als open data gepubliceerd; de jaarberekening komt voor een volledig jaar op hetzelfde uit en is uit te leggen. De app meldt dat de loonstrook een paar euro kan afwijken.
