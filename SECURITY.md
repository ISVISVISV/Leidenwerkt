# Beveiliging

Leidenwerkt is een statische website zonder server en zonder opslag van gegevens. De Content-Security-Policy blokkeert netwerkverbindingen vanuit de pagina (`connect-src 'none'`).

Een kwetsbaarheid gevonden? Meld het niet in een openbare issue, maar via een privé "security advisory" in de repository. U krijgt binnen een week een reactie.
